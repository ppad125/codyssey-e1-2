# 06. Ctrl+C / EOF 안전 종료

퀴즈 풀이 중 `Ctrl+C`(KeyboardInterrupt), 메뉴에서 `Ctrl+D`(EOFError)를 눌러도 오류 메시지 없이 저장 후 종료합니다.

> 검증용 복사본 폴더(`main.py`, `state.json` 복사)에서 `python3 main.py`를 실행한 **실제 출력**입니다. 저장소의 데이터가 바뀌지 않도록 복사본에서 실행했습니다.

```text
$ python3 main.py
# Ctrl+C
저장된 데이터를 불러왔습니다. (퀴즈 6개)
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 : 1
퀴즈를 시작합니다! (총 6문제)
----------------------------------------
[문제 1]
우사기의 제초 자격증 등급은?

1. 1급
2. 2급
3. 3급
4. 5급

정답을 선택하세요 (1-4): ^C
입력이 중단되어 저장 후 게임을 종료합니다.

# Ctrl+D (EOF)
저장된 데이터를 불러왔습니다. (퀴즈 6개)
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 : ^D
입력이 중단되어 저장 후 게임을 종료합니다.
```
