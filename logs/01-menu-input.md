# 01. 메뉴와 입력 예외 처리

앞뒤 공백이 있는 `  3  `은 공백을 제거해 3번(목록)으로 처리하고, `abc`(숫자 아님), `9`·`0`(범위 밖), 빈 입력은 안내 후 다시 입력받습니다.

> 검증용 복사본 폴더(`main.py`, `state.json` 복사)에서 `python3 main.py`를 실행한 **실제 출력**입니다. 저장소의 데이터가 바뀌지 않도록 복사본에서 실행했습니다.

```text
$ python3 main.py
저장된 데이터를 불러왔습니다. (퀴즈 6개)
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 :   3  
총 6개의 퀴즈가 있습니다.
----------------------------------------
[1] 우사기의 제초 자격증 등급은?
[2] 헌책방에서 돈을 내지 않고 그냥 가려고 했던 캐릭터는?
[3] 하치와레가 존경하는 캐릭터는?
[4] 쿠리만쥬가 가지고 있는 자격증은?
[5] 도토리로 디제잉 하는 캐릭터는?
[6] 치이카와의 작가 이름은?
----------------------------------------
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 : abc
잘못된 입력입니다. 1- 5 사이의 숫자를 입력해주세요.
선택 : 9
잘못된 입력입니다. 1- 5 사이의 숫자를 입력해주세요.
선택 : 0
잘못된 입력입니다. 1- 5 사이의 숫자를 입력해주세요.
선택 : 
입력값이 없습니다. 다시 입력해주세요.
선택 : 5
게임을 종료합니다.
```
