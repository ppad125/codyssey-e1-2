# 04. 재실행 후 데이터 유지

03번에서 프로그램을 종료한 뒤 다시 실행했습니다. 첫 줄에 `퀴즈 7개`를 불러왔다고 나오고, 목록과 최고 점수가 그대로 유지됩니다.

> 검증용 복사본 폴더(`main.py`, `state.json` 복사)에서 `python3 main.py`를 실행한 **실제 출력**입니다. 저장소의 데이터가 바뀌지 않도록 복사본에서 실행했습니다.

```text
$ python3 main.py
저장된 데이터를 불러왔습니다. (퀴즈 7개)
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 : 3
총 7개의 퀴즈가 있습니다.
----------------------------------------
[1] 우사기의 제초 자격증 등급은?
[2] 헌책방에서 돈을 내지 않고 그냥 가려고 했던 캐릭터는?
[3] 하치와레가 존경하는 캐릭터는?
[4] 쿠리만쥬가 가지고 있는 자격증은?
[5] 도토리로 디제잉 하는 캐릭터는?
[6] 치이카와의 작가 이름은?
[7] [시연용] 1 + 1 = ?
----------------------------------------
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 : 4
최고 점수: 83점
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 : 5
게임을 종료합니다.
```
