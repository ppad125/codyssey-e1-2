# 05. 파일 없음·손상·백업 복구

파일이 없으면 기본 퀴즈 5개로 시작합니다. 파일이 손상되면 손상 파일을 `state.corrupted.json`으로 보관하고 기본 퀴즈로 복구합니다. 저장할 때마다 만들어 두는 `state.json.bak`을 복사하면 직전 데이터(퀴즈 6개, 83점)로 되돌릴 수 있습니다.

> 검증용 복사본 폴더(`main.py`, `state.json` 복사)에서 `python3 main.py`를 실행한 **실제 출력**입니다. 저장소의 데이터가 바뀌지 않도록 복사본에서 실행했습니다.

## 파일이 없을 때

```text
$ rm state.json   # 파일 없음
저장된 데이터가 없어 기본 퀴즈로 시작합니다.
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 : 5
게임을 종료합니다.
```

## 파일이 손상됐을 때와 백업으로 복구

```text
$ echo "{ broken" > state.json   # 파일 손상
데이터 파일이 손상되어 기본 퀴즈로 복구합니다.
손상된 파일은 state.corrupted.json로 보관했습니다.
직전 정상 데이터는 state.json.bak에 있습니다.
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 : 5
게임을 종료합니다.
$ ls
main.py
state.corrupted.json
state.json
state.json.bak
$ cp state.json.bak state.json   # 백업으로 복구
저장된 데이터를 불러왔습니다. (퀴즈 6개)
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 : 4
최고 점수: 83점
========================================
 치이카와 퀴즈 게임 
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택 : 5
게임을 종료합니다.
```
